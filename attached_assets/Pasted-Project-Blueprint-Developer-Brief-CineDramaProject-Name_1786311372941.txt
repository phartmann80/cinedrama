Project Blueprint & Developer Brief: CineDramaProject Name: CineDramaTarget Platform: Android (.apk direct download & Google Play submission setup)Landing Page Domain: cinedrama.appGitHub Repository: https://github.com/phartmann80/cinedramaDeployment Stack: Vercel (Front-end Landing Page) + Custom Linux VPS Backend (API / Streaming)1. Executive Summary & Core ObjectiveCineDrama is a high-engagement, vertical short-form drama streaming platform built specifically for mobile devices. Users watch episodic 1–3 minute cinematic stories (e.g., Billionaire Revenge, Sci-Fi Thrillers, Romantic Suspense) in a vertical swipe feed similar to TikTok/Reels.MVP Scope: 1. Build a high-converting web landing page deployed via Vercel on cinedrama.app.2. Build a high-performance Android App (.apk) using Flutter or React Native.3. Deploy a custom backend server to handle streaming, APIs, and user authentication.4. Integrate a complete AI generation pipeline for content production.2. Custom Backend ArchitectureStack: Node.js (Express) or Python (FastAPI).Database: PostgreSQL (User profiles, drama metadata, episode unlock states, coin balances).Video CDN / Storage: Cloudflare R2 or AWS S3 paired with HLS/MP4 streaming to ensure sub-second video buffering globally.Authentication: JWT (JSON Web Tokens) or Firebase Auth for fast mobile login.3. Complete AI Model Stack (Production Pipeline)The platform utilizes a multi-model AI pipeline to generate, voice, and composite video content before ingestion into the backend storage.Content LayerAI Tool / ModelTechnical FunctionScriptwriting & NarrativeClaude 3.5 Sonnet / GPT-4oStory generation, scene breakdowns, episode cliffhangers, visual prompting commands.Video GenerationLuma Dream Machine / Runway Gen-3 / Wan 2.7Text-to-Video and Image-to-Video rendering in portrait ratio ($9:16$).Character Voice & AudioElevenLabs API / Chatterbox-TurboMultilingual cinematic voice narration, emotional voice cloning, and character dialogue.Voice-to-Lip SynchronizationSync Labs (LivePortrait) / SadTalkerSyncing character speech audio strictly onto generated video faces.Upscaling & Frame InterpolationTopaz Video AI / Real-ESRGANUpscaling raw output videos to crisp 1080x1920 (60 FPS) vertical video.4.
